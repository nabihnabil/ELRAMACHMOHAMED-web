# محمد الرماش · مراجعة الحلقة
نسخة ثابتة للنشر على GitHub Pages، بثلاثة أقسام فقط: كلام المحاور بالتوقيت، مبيان أدائه، والتعليقات الناقدة أو المختلطة حوله من اللقطة المحفوظة. التصنيف أولي والتداخل الصوتي ليس عدد مقاطعات مؤكدة. النص من الكابشن الآلي وإسناد المتحدث من تحليل الصوت.

افتح index.html عبر خادم ويب؛ لا تحتاج أدوات بناء أو مفاتيح API. لا تتضمن النسخة التسجيل الصوتي أو أوزان النماذج أو الملاحظات الشخصية. التعليقات مقتبسة بصيغتها الأصلية مع رابط مصدرها، ولا تعبر عن موقف صاحب المنصة.
