# مرآة الحوار · محمد الرماش
منصة ثابتة على GitHub Pages: نص المتدخلين الأربعة بالتوقيت، المقارنة الزمنية، تقسيم المداخلات إلى دقيقة أو دقيقتين أو خمس دقائق، والتعليقات في سياقها.

## حالة التدقيق
أعيد فحص الصوت محليًا في 25 نافذة مرتبطة بالتعليقات والسياق بمجموع 922.29 ثانية، وأربع نوافذ إضافية للذروة بمجموع 158.5 ثانية. تتداخل بعض النوافذ. استخدم تفريغ Whisper مستقل عن كابشن يوتيوب وإعادة Nemotron على المقاطع القصيرة. هذا فحص آلي، لا استماع بشري ولا مرجع صحيح لتقييم DER. ثبات النموذج مع نفسه لا يثبت صحة الهوية أو حدود الكلمة. لا توجد مقاطعات مؤكدة بالاستماع.

سُحب 21 ربطًا موضوعيًا ضعيفًا وربط واحد عند نهاية التسجيل (موسيقى فقط)، وصُحح سياقان. العدد الحالي: 14 تعليقًا يذكر توقيتًا، 30 سياقًا مقترحًا غير مؤكد، و226 تعليقًا عامًا بلا إسناد لحظة محددة. الإحالة بتوقيت صريح ليست تصديقًا لادعاء التعليق. تفكيك التعليق المختلط يفصل الهجوم الشخصي عن الملاحظة على إدارة الحلقة، ولا يصفه كله بأنه منطقي أو صحيح.

## مواضع الدخول أثناء الكلام
أُبقي الفرق بين 22 مرشحًا بحدود النشاط الخام و67 بالوصل الأوسع لفجوات ≤1ث. تتصدر نافذة 40–45 دقيقة بكلا المعيارين (6 مقابل 20)، حول نهاية الحقوق والإعدامات ثم القواعد والضربات. الكشف لا يثبت المقاطعة؛ فقد يكون توضيحًا أو تأييدًا أو انتقالًا. يتغير ترتيب المحاور الكاملة عند تغيير المعيار.

أعداد الجدول الزمني هي العودات التقديرية حسب قاعدة التحليل السابق؛ لا تساوي المقاطع النصية ولا المقاطعات المؤكدة. النص المعروض من الكابشن الأصلي، لا من التفريغ المستقل، الذي يعرض منفصلًا عند مراجعة الربط.

لا تحتاج النسخة مفاتيح API أو حسابًا لفتحها، ولا تضم الصوت أو أوزان النماذج أو ملاحظات شخصية. التعليقات لقطة محفوظة لا تتحدث تلقائيًا. الآراء المنقولة لا تعبر عن موقف صاحب المنصة.
