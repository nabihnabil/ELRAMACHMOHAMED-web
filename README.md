# مرآة الحوار · محمد الرماش
منصة ثابتة على GitHub Pages: نص المتدخلين الأربعة بالتوقيت، جدول مقارنة أزمنة الكلام والكلمات والعودات التقديرية، أربعة مسارات زمنية وتزامن الأصوات، وتعليقات الجمهور مرتبطة بسياقها.

## الربط والتصنيف
- 15 تعليقًا يذكر توقيتًا صريحًا؛ النافذة تعرض الكلام المحيط به، دون افتراض أن كل النص هو موضوع النقد.
- 51 تعليقًا له سياق موضوعي مقترح. لا يمثل الربط إثباتًا لقصد المعلّق، ويُعرض بهذه الصفة بوضوح.
- 204 تعليقات عامة أو غير محددة لا يُختلق لها توقيت. يمكن البحث في الحوار من داخلها.
- التصنيف الأولي يميز نقد الأداء/الطرح والهجوم الشخصي والتعليق الذي يجمعهما؛ يحتاج مراجعة بشرية. نقل النص لا يعني إقرار اتهاماته.

النص من كابشن يوتيوب الآلي وإسناد المتحدثين من تحليل الصوت السابق. تزامن الأصوات ليس عدد مقاطعات مؤكدة، ولا يساوي عدد مقاطع النص عدد التدخلات. المقارنة تختار النطاق الزمني نفسه لكل المتحدثين؛ مجموع أزمنة الأصوات يحسب التداخل لكل صوت، بخلاف مدة النطاق الفعلية.

افتح `index.html` عبر خادم ويب؛ لا تحتاج أدوات بناء أو مفاتيح API. لا تتضمن النسخة التسجيل أو أوزان النماذج أو الملاحظات الشخصية. لقطة التعليقات محفوظة ولا تتحدث تلقائيًا.
